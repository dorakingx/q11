## Architecture (contracts for parallel implementation)
### Game layer (`src/game`, no React)
- `Screen` gains `'dispatch'` (spray / answer-check phase between Challenge and the Why replay). Flow: city (`'missions'` screen id kept) → briefing (district goal) → training → challenge → **dispatch** → debrief ("Why?" replay) → result → city.
- `Settings` gains `language: 'en' | 'ja'` and `freeRoam: boolean`. `SaveData` v2 = `{ version: 2, progress, settings, tutorialDone: boolean }`; `parseSave` migrates v1 → v2 (progress/settings kept, tutorialDone = any progress). Unknown/corrupt → reset with notice (unchanged).
- `src/game/city.ts`: `DISTRICTS` (ordered; id ↔ missionId ↔ art kind), `districtStatus(id, progress, freeRoam)`, `firstAvailable(progress)`.
- `src/game/effects.ts`: `buildEffects(debrief, reducedMotion)` → deterministic `EffectTimeline { durationMs, events[] }` with events `trucks-arrive`, `crew-run{q,crew}`, `spray-start{q,crew}`, `impact{q,crew,before,after,effect: extinguished|changed|ignited}`, `reveal-remaining{qs}`, `alarms{syndrome}`, `outcome{result}`, `done`; `resultType(debrief)`: `restored | safe-pattern | still-burning | logical-failure`. Per-house `after` = engine residual letter at q (asserted = before ⊕ crew).
- Reducer: `CONFIRM`/`STAND_DOWN_CONFIRM` → `'dispatch'` (progress merged once, here); `DISPATCH_DONE` → stays on `'dispatch'` with `dispatchDone: true` (result overlay); `OPEN_WHY` → `'debrief'`; `DISPATCH_SKIP` jumps to done. All of these are idempotent (a second CONFIRM / DISPATCH_DONE is a no-op) — tested.
### UI layer
- `src/ui/i18n/`: `LanguageProvider`, `useT()`; `en.ts` and `ja.ts` share one key type (TS enforces completeness); mission kid texts in `missions.en.ts`/`missions.ja.ts`.
- `src/ui/art/`: pure SVG parts (House, Detector, Firefighter, FireTruck, Hose/Stream, Splash, Beacon, Smoke, Flag, city tiles) + `Gallery.tsx` for visual review. No React state, no text except X/Z/Y letters.
- `src/ui/city/`: CityMap screen (districts as real `<button>`s over one SVG), truck drive, HUD, Dispatch panel.
- `src/ui/scene/`: Scene (replaces Board for grid/line codes; the wires board is re-skinned as bridge/lab lanes), planning preview, detector highlight, spray player (plays an EffectTimeline; skip; reduced-motion stepper), result overlay (4 types + beacon), Why comparison.
- Keep: engine, fixtures, bridge, cloud panel (moved under Details), Python, Qollab files (bundle rebuilt).
